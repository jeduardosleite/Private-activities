# Fundamentos de Python

## Objetivo

Consolidar conhecimentos em Python e desenvolver habilidades de programação aplicadas à **análise de dados, automação de tarefas e resolução de problemas**.


## Conceitos abordados

- **Variáveis e tipos de dados:** utilização de `int`, `float`, `str` e `bool`.
- **Listas:** armazenamento e manipulação de conjuntos de valores.
- **Dicionários:** organização de dados em pares de chave e valor.
- **Condicionais:** tomadas de decisão com `if`, `elif` e `else`.
- **Laços de repetição:** utilização de `for` e `while`.
- **Tratamento de exceções:** validação de entradas com `try`, `except` e `ValueError`.
- **Operadores:** operações aritméticas, relacionais e lógicas.
- **F-strings:** formatação de textos, números e resultados.

## Funções e métodos utilizados

| Função / Método | Descrição |
|---|---|
| `print()` | Exibe informações. |
| `input()` | Recebe dados do usuário. |
| `int()` / `float()` | Converte valores numéricos. |
| `range()` | Gera sequências de números. |
| `len()` | Retorna a quantidade de elementos. |
| `sum()` | Soma valores numéricos. |
| `max()` | Retorna o maior valor. |
| `round()` | Arredonda números. |
| `append()` | Adiciona elementos a uma lista. |
| `values()` | Retorna os valores de um dicionário. |
| `get()` | Acessa valores de um dicionário pela chave. |
| `upper()` / `strip()` | Formata e trata strings. |

## Tecnologias e bibliotecas

- **Python:** linguagem principal.
- **Google Colab:** ambientes de desenvolvimento e execução.
